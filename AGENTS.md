# AGENTS.md — Dotfiles Repo

GNU Stow, XDG-compliant, cross-platform (macOS / Linux / WSL). Thin dispatchers source a layered config chain; all user config lives under `~/.config`.

---

## Shell Config Load Order

Exact source sequence — do not reorder:

```text
~/.bashrc / ~/.zshrc
  → common.sh                      XDG dirs, PATH, editor, aliases
  → darwin.sh OR linux.sh          OS base (linux.sh includes SSH agent)
  → {ubuntu,fedora,rhel}.sh        distro overlay, Linux only
  → wsl.sh                         Windows interop, WSL only
  → ~/.config/bash/.bashrc
    OR ~/.config/zsh/.zshrc
  → ~/.config/shell/local.sh       machine-local overrides, sourced LAST
```

Dispatchers are thin: OS detection + source chain + `local.sh`. Do NOT add tool setup, aliases, or exports directly to dispatchers.

## Coding Conventions

**XDG paths** — config: `~/.config`, state: `~/.local/state`, cache: `~/.cache`. Never write to bare `~`.

**PATH deduplication** — always guard before adding:

```bash
case ":$PATH:" in *":$dir:"*) ;; *) PATH="$dir:$PATH" ;; esac
```

Bare prepend/append duplicates entries across nested shells and tmux panes.

**Shell-specific variables** — `HISTCONTROL`, `HISTFILESIZE`, `HISTSIZE` are bash-only. Guard them in shared files:

```bash
if [ -n "$BASH_VERSION" ]; then
    HISTCONTROL=ignoreboth
fi
```

Exporting bash-only vars pollutes every child process's environment.

**Machine-local config** — `~/.config/shell/local.sh` is not tracked. Sourced last so it always wins. Never commit machine-specific config or credentials to the repo.

**Brew prefix** — cache once per session: `BREW_PREFIX=$(brew --prefix)`. Never call `brew --prefix` inline; it forks a subprocess on every use.

**Catppuccin Macchiato** — the theme for all tools. Do not introduce other themes.

## Zsh Plugin Loading Order

Invariant — do not change:

1. `compinit` — must run before any plugin that uses completions
2. `fzf-tab` — must follow `compinit`; must precede any ZLE widget-wrapping plugin
3. `zsh-autosuggestions` — wraps ZLE `self-insert` and related widgets
4. `fast-syntax-highlighting` — **must be sourced last**; wraps all ZLE widget chains present at source time

Violating this order causes broken completions, missing syntax highlighting, or silent widget conflicts.

## Adding a New OS Distribution

1. Create `shell/.config/shell/os/{distro-id}.sh` where `$ID` matches `/etc/os-release`
2. Dispatchers auto-load it — no other changes needed
3. Follow `linux.sh` for the base patterns (PATH dedup, BASH_VERSION guards)

---

## Adding a New Stow Package

1. Create `mypackage/` mirroring the home directory structure
2. Add to `PACKAGES_TO_STOW` in `install.sh`
3. Add to the `stow -D` line in `uninstall.sh`
4. Add a row to the packages table in `docs/install.md`
5. Verify: `stow -nv mypackage`

If the package includes a submodule or requires steps beyond stow (symlink creation, plugin manager, external download), document it in `docs/dependencies.md`.
